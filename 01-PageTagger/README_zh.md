# 🏷️ Smart Tagger for Xournal++
**让 Xournal++ 成为你专属的“沉浸式”学习与复习神器**

Smart Tagger 是一个为 Xournal++ 量身打造的增强插件。如果你经常在 Xournal++ 里阅读长篇 PDF、做考研笔记、刷题或看文献，这个插件将彻底改变你的学习体验。

它能帮你快速给页面打上“难点”、“重点”、“错题”等标签，并在期末复习时，带你在这些重要页面之间“瞬间移动”。

## ✨ 核心亮点：它能为你做什么？

* 👁️ **X 光透视复习**：在复习时，一键飞到有“错题”的页面。属于这道错题的红色备注会**自动浮现**；当你看完切到下一页时，上一页的备注又会像幽灵一样**自动隐藏**，绝不干扰你的正常阅读。
* 📖 **按章节复习**：书太厚？你可以随手在每一章开头定一个“章节起点”。复习时，你可以选择**只在当前这一章**里循环查看“重点”或“错题”，再也不会满书乱跑。
* 🚀 **意念级瞬移（剪贴板起飞）**：看到想复习的词（比如 `hard`），直接选中并复制（`Ctrl+C` 或 `Ctrl+X`），按下浏览键，插件会直接带你飞过去，连搜索框都省了！
* 📊 **一键期末大纲**：书看完了？按下一个键，插件会自动把全书的重点、难点和你的备注，按章节整整齐齐地排版成一份复习大纲，直接贴在画面上。
* 🎨 **为每本书定制专属按钮**：看高数时，你的工具栏可以是 `[代数] [几何] [错题]`；看英语时，可以是 `[语法] [长难句] [生词]`。**这些配置会直接保存在这本 PDF 里**，下次打开依然在！

## 🛠️ 极简安装指南

1. 找到你的 Xournal++ 插件文件夹：
   * **Windows**: 打开文件资源管理器，在地址栏输入 `%LOCALAPPDATA%\xournalpp\plugins\` 并回车。
   * **macOS / Linux**: 通常在 `~/.local/share/xournalpp/plugins/` 或 `~/.xournalpp/plugins/`。
2. 在该目录下新建一个名为 `Tagger` 的文件夹。
3. 把下载好的所有 `.lua` 文件放进这个文件夹。
4. 打开 Xournal++，点击菜单栏的 `插件 (Plugin)` -> `插件管理器 (Plugin Manager)`，勾选启用本插件。
5. **完全关闭并重新打开 Xournal++**，大功告成！

## 🚀 第一次使用：定制你的专属工具栏

刚装好插件时，工具栏按钮可能是默认的或空白的。别急，花 10 秒钟定制一下：

**第一步：设置你想要的 6 个标签**
1. 在任何地方（记事本、网页等）打下你想要的 6 个标签名字，用逗号隔开。例如：
   `math, physics, chem, core, hard, todo, skip`
2. 选中它们并复制（`Ctrl+C`）或者剪切 (`Ctrl+X`)。
3. 回到 Xournal++，按下 **`Alt+X`**。插件会提示你配置成功！
4. **重启 Xournal++**，你会发现最上方的工具栏已经出现了属于你的 6 个彩色快捷按钮！

*(进阶玩法：如果你不喜欢默认颜色，你可以复制 6 个颜色代码，比如 `#FF0000, #00FF00...`，再按 `Alt+X`，你的按钮就会换上新皮肤！)*

## ⌨️ 常用快捷键速查表

熟练使用快捷键，会让你的学习效率翻倍：

| 快捷键 | 功能名称 | 它是用来干嘛的？ |
| :--- | :--- | :--- |
| **`Alt+A`** | 📝 **带备注打标** | 复制一段文字（格式如 `hard: 这道题用了洛必达法则`），按下此键，打上标签并留下隐形红字备注。 |
| **`Alt+D`** | 🗑️ **删除标签** | 想要删掉当前页的某个标签？按它。 |
| **`Alt+F`** | 🌍 **全书复习** | 弹窗让你选择要复习什么（比如选 `hard`），然后带你在**全书**所有 `hard` 页面穿梭。 |
| **`ALt+C`** | 📖 **本章复习** | 同上，但只在**当前这一章**里循环，适合分块学习！ |
| **`Alt+V`** | 🔤 **生词本** | 复制一个生词按下此键，它会静默跑到页面右上角的蓝色专属区，适合学外语。 |
| **`Alt+X`** | 🔄 **同步与换肤** | 读取你剪贴板里的词或颜色，一键重置你的侧边栏工具按钮。 |
| **`N/A`** | ⚡ **快速打标** | 呼出一个小菜单，快速给当前页盖上一个标签。 |
| **`N/A`** | 📊 **生成大纲** | 一键把全书的标签和备注汇总成一份目录，自动排版显示。 |
| **`N/A`** | 🧹 **打扫战场** | 如果你觉得页面乱了，按它，所有的红字备注都会乖乖隐身。 |

## 💡 新手必学的三个“神仙操作”

**1. 如何给 PDF 划分章节？**
你看书看到了新的一章，想要在这里定一个锚点：
选中标题（比如“第三章：微积分”），按下 `Ctrl+X`（剪切），然后按随便点击工具栏上的 `[chapter]` 按钮。插件会问你是不是要把这当作章节名，点“是”。右上角会立刻出现一个灰色的专属徽章。

**2. 意念检索法**
复习时，你不想按快捷键再用鼠标去选要复习哪个标签。
你可以直接在屏幕上选中 `core` 这个词，按下 `Ctrl+X`（把它剪切掉），然后按 **`Alt+F`**。系统连问都不会问，直接带你飞到全书第一个 `core` 所在的位置！

**3. “阅后即焚”的清爽感**
使用本插件在页面间跳跃复习时，千万不要用鼠标滚轮翻页！
看完这页的红字备注后，**再次按下 `Alt+F` (或 C)** 去下一页，插件就会自动帮你把刚才那页的红字藏起来。这才是最纯正的沉浸式体验。
